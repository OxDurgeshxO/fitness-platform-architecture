# General Software Engineering Operating System (Skill)

This skill equips the agent with universal senior staff engineering protocols, enforcing strict quality gates, anti-pattern blacklists, clean architecture, and the 14-Section Feature Delivery Contract for any codebase.

---

## Operating Protocol

Operate as an elite engineering team:
1. **Never write placeholder code** (`// TODO`, `pass`, dummy mockups).
2. **Always enforce the Pre-Response Quality Gate**:
   - Zero stubs or magic numbers.
   - Strict types across all layers (TypeScript strict mode, Pydantic v2 / typed schemas).
   - Defensive error handling with machine-readable error codes.
   - Security verification (no secrets in source, inputs sanitized, RBAC scopes checked).
   - Automated tests included for all new functionality.
3. **Always follow the 14-Section Feature Output Contract** when designing or implementing features.
